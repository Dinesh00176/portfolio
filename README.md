# M. Dinesh Kumar - AI/ML & Full Stack Portfolio

A clean, modern, and responsive personal portfolio website built with **React**, **Tailwind CSS**, and **Lucide React** icons for **M. Dinesh Kumar** — Artificial Intelligence and Machine Learning undergraduate at Easwari Engineering College, Chennai.

---

## 🌟 Key Features

- **Dark / Light Mode Toggle**: Seamless theme switching with system detection and persistence in `localStorage`.
- **Glassmorphic Navigation Bar**: Frosted glass sticky header with active scroll spy, mobile drawer, and zero download buttons (compliant with requirements).
- **Interactive AI/ML Hero & Terminal**: Featuring interactive code previews for Convolutional Neural Network (CNN) denoising models and developer profile inspection.
- **Academic Foundation Spotlight**: Highlighting B.E. Computer Science & Engineering (AI & ML) at Easwari Engineering College, Chennai (2024–2028).
- **Categorized Technical Skills**: Filterable skills across AI & ML, Web Technologies, Programming Languages, and Databases.
- **Featured Projects Showcase**:
  - **PetConnect Pet Adoption Web App** (`Node.js`, `Express.js`, `MongoDB`, `HTML/CSS/JS`)
  - **Underwater Image Denoising using CNN** (`Python`, `TensorFlow/Keras`, `OpenCV`) with an interactive before/after noise removal simulator!
  - **E-Commerce Cart Simulator** (`Spring Boot`, `Java`, `MySQL`, `HTML/CSS/JS`)
- **Professional Experience Timeline**: Detailing Full Stack Development Internship at TechnoHacks Solutions.
- **Dynamic & Custom Certifications Hub**:
  - Starts clean so you can add all your verified certificates manually.
  - **Image Support**: Upload certificate images (PNG, JPG, WEBP, SVG) directly from your device with automatic client-side compression, or provide an image link.
  - **Certificate Lightbox**: Click any certificate image to view high-resolution preview in a full-screen modal.
  - All additions and image proofs persist across sessions in `localStorage`.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
